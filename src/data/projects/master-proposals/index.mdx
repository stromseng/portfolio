IDI's [website](https://www.idi.ntnu.no/education/fordypningsprosjekt.php) for showcasing the master thesis proposals is a bit of a mess. This started as a case study for vibe coding, but quickly turned into a full fledged project. 

We have several features which enhance the user experience:
- Better filtering and sorting
- AI Summaries of the projects
- An elo ranking system to help you sort the projects you like the most
- Dark Mode :D
