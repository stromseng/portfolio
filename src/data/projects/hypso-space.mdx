This was my Bachelor's project.

If you wanna learn more, you can go read the docs at the GitHub [repo](https://github.com/NTNU-SmallSat-Lab/outreach-website).

### TL;DR

We built a website for the NTNU SmallSatLab organization. I learned a lot about how to build a website with a headless CMS and a modern frontend framework. Also had to deal with some backend stuff, like hosting and deploying the website.

Overall I was pretty pleased with the result at the time, looking back there are clearly improvements to be made, but it was a great learning experience.
