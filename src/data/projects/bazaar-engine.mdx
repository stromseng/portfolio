Contributed to multiple features. Including refactoring the engine and UI.

I refactored the ui to use shadcn/ui and tailwindcss.
I also ended up refactoring the engine to a more modular approach, using an event bus and the command pattern.
Trying out web workers was also a horrifying experience, if you know you know. 

I really enjoyed learning about how you implement a system where multiple cards interact with each other. 
Reading the json for all the cards, and reverse engineering the engine was quite fun.
